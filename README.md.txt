# Iris Flower Classification

## Project Overview

This project focuses on classifying iris flowers into three species:
Setosa, Versicolor, and Virginica using machine learning.

## Objective

The objective is to predict the species of an iris flower using its
sepal and petal measurements.

## Dataset

The Iris dataset is obtained from `sklearn.datasets.load_iris()`.

It contains 150 samples and four features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The target classes are:

- Setosa
- Versicolor
- Virginica

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow

1. Load the Iris dataset
2. Create a Pandas DataFrame
3. Perform Exploratory Data Analysis
4. Visualize the data
5. Analyze important features
6. Split the dataset into training and testing sets
7. Train Logistic Regression
8. Train K-Nearest Neighbors
9. Evaluate both models
10. Compare model performance
11. Select the final conclusion

## Machine Learning Models

### Logistic Regression

A classification model used to predict the iris species.

### K-Nearest Neighbors

A classification algorithm that predicts the class based on nearby
data points.

## Evaluation Metrics

The models were evaluated using:

- Accuracy
- Confusion Matrix
- Precision
- Recall
- F1-score

## Results

Both Logistic Regression and K-Nearest Neighbors showed similar
performance on the test dataset.

## Conclusion

The project demonstrates the use of Exploratory Data Analysis,
visualization, and supervised machine learning for Iris flower
classification.
